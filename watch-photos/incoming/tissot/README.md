## About exact model names

These are identified by sight. The dial on most of them only says
`TISSOT 1853`, so the exact reference cannot be read from the photo. The
folder names are the collection family, and the file names describe the
colourway. For catalog-grade names and references, photograph the **caseback**
(the reference is engraved between the lugs) or the **swing tag**.
